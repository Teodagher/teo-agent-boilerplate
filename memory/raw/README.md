# Raw sources (immutable)

The verbatim evidence behind the wiki: chat statements, emails, documents, tool output.
Filed only with `python3 tools/memory.py file`, named `YYYY-MM-DD_<kind>_<slug>.<ext>`
(the event's date). Never edited or deleted: hooks block it. Corrections go in the wiki as a
`SUPERSEDES:` evidence line. Pages cite these files as `[[raw/<file>]]`.
